# مميزات ثوابتي وسجل التنفيذ

هذا الملف يتابع ما طُلب وما نُفّذ فعليًا وما يحتاج إعدادًا خارجيًا.
كل وحدة جديدة تستخدم نماذج واضحة، مستودع بيانات، وCubit مستقل؛ البيانات تحفظ
محليًا أولًا. لا تُرفع بيانات شخصية تلقائيًا.

## فكرة التطبيق

ثوابتي رفيق يومي يجمع تنظيم الوقت ومتابعة العبادات في مكان واحد: تعرف موعد
الصلاة القادم، تنظّم اجتماعاتك وتذكيراتك، تختار وردك وتتابع إنجازه، وتسجّل
النوافل والقضاء. وفي المكتبة
تقرأ أو تستمع إلى مواد مرتبطة بمصادرها. الإنجاز سجل شخصي يدوّن ما تؤكده أنت.

التصميم بالعربية أولًا مع الإنجليزية والأوردية؛ خلفية بيضاء في النهار وسوداء
في الوضع الداكن، أخضر هادئ ولمسات ذهبية، وأزرار واضحة وحالات فارغة مفيدة.

## قرارات المستخدم

- الاحتفاظ باسم ثوابتي والهوية الخضراء والذهبية.
- البدء بالتخزين المحلي، وتجهيز الربط بالخادم لمرحلة لاحقة.
- الورد: تذكير وفتح تطبيق القراءة. بقرار لاحق للمالك: مساعد عائم اختياري (مغلق افتراضيًا) فوق تطبيق القراءة المختار فقط؛ لا يسجّل القراءة أبدًا، والتأكيد يدوي. مراقبة الاستخدام اختيارية ومنفصلة ولا تُستخدم إلا لإخفاء البطاقة.

## نطاق التنفيذ

| الميزة | ما يجب أن توفره | الحالة |
|---|---|---|
| المنبه والمواعيد | إضافة وتعديل وحذف موعد، تقويم وأجندة، تاريخ/وقت، ملاحظات وتذكير بصوت إشعار | منفّذ محليًا؛ هذا تذكير إشعاري وليس منبهًا شخصيًا مستمر الرنين |
| التقويم الخارجي | اختيار تقويم الجهاز، قراءة المواعيد واستيرادها وتصدير موعد محلي بعد الإذن | منفّذ لأندرويد؛ ظهور Google وغيره يعتمد على الحسابات والتقاويم المتزامنة في الجهاز |
| Google Meet | حفظ رابط اجتماع وفتحه؛ فتح إنشاء اجتماع في متصفح Google | منفّذ؛ إنشاء المؤتمر تلقائيًا عبر API مؤجل لإعداد OAuth |
| الورد اليومي | خطة صفحات وتذكير يومي، اختيار تطبيق قراءة مثبت وفتحه، تسجيل الإنجاز يدويًا | منفّذ؛ فتح تطبيق خارجي لا ينقله تلقائيًا إلى رقم الصفحة |
| المساعد العائم فوق تطبيق القراءة | مفتاح في خطة الورد (مغلق افتراضيًا)، شرح قبل فتح إعدادات «العرض فوق التطبيقات»، بطاقة قابلة للسحب بهدف اليوم وزرّي «تم» و«إغلاق»، «تم» يفتح شاشة الورد بسؤال تأكيد ولا يسجّل وحده؛ إخفاء تلقائي اختياري عند مغادرة التطبيق (يتطلب «الوصول إلى بيانات الاستخدام») | منفّذ لأندرويد ومجرَّب على محاكي API 36. حدود: بلا إذن العرض يعمل الورد كما كان مع تنبيه؛ بلا إذن الاستخدام تبقى البطاقة حتى الإغلاق أو ٣٠ دقيقة (وتظهر أيضًا فوق تطبيقنا إن عدت إليه)؛ بعض التطبيقات مثل الإعدادات والتطبيقات المالية تخفي النوافذ العائمة عمدًا؛ أجهزة بعض الشركات (شاومي/هواوي…) قد تحتاج إذن «النوافذ المنبثقة» إضافيًا؛ يحتاج إقرارات Play (انظر PLAY_STORE_COMPLIANCE.md) |
| النوافل | سجل للصلاة والصيام مع التاريخ والوحدات والملاحظات | منفّذ |
| الصلاة | المواقيت والإعدادات الحالية، وتتبع يدوي للصلاة في يوم تختاره | منفّذ |
| الصلاة الفائتة | رصيد لكل صلاة، قضاء وتعديلات بسبب وتاريخ؛ يمنع الرصيد السالب | منفّذ؛ لا يحوّل سنوات العمر إلى دين تلقائيًا |
| الخادم | SQLite، إصدارات وتغييرات معلقة، SyncCoordinator، وHttpSyncGateway وAutoSyncService يرفعان المعلّق عند عودة الإنترنت | منفّذ في التطبيق؛ يبقى خاملًا حتى تخزين `sync_endpoint_url` (https فقط) و`sync_token`؛ لا خادم جاهز ولا شاشة إعداد بعد. العقد: PUT `/documents/{ns}/{id}` ويرد `{"revision": n}` |
| الاختصارات | تثبيت اختصار للتسبيح والصلاة والورد والمواعيد والمكتبة | منفّذ لأندرويد؛ يتطلب دعم مشغّل الشاشة وتأكيد النظام |
| الأحاديث والقصص | ٦ ملخصات موثقة، بحث ومفضلة، قراءة صوتية؛ إضافة رابط صوت/صورة/فيديو | منفّذ؛ الفيديو المباشر (mp4/webm/m3u8) يُشغَّل داخل التطبيق بمشغّل مع تحكم وملء الشاشة، وروابط الصفحات مثل يوتيوب تُفتح في التطبيق الخارجي؛ لا توجد مكتبة وسائط مستضافة جاهزة |

## التحقق السابق الذي يجب الحفاظ عليه

الفحص السابق وصل إلى 156 اختبارًا ناجحًا، وتشغيل الرئيسية على محاكي أندرويد
مستقل. سيضاف هنا عدد الاختبارات الجديد، نتائج البناء، وصور الشاشات بعد التنفيذ.

## ملاحظات مهمة للوظائف

- الصلاة الفائتة تبدأ بتقدير أو أعداد يدخلها المستخدم، ولا تُحسب سنوات فائتة
  تلقائيًا باعتبار كل الأيام واجبة عليه.
- فتح ترتيل أو تطبيق آخر لا يثبت قراءة صفحات أو آيات؛ الإنجاز يسجل يدويًا.
- ربط تقويم الجهاز يتيح التقويمات التي توفرها التطبيقات والحسابات الموجودة فيه.
  Google Calendar API وإنشاء روابط Meet يتطلبان إعداد OAuth، ولا يُعرض الربط
  باعتباره متصلًا قبل نجاحه.
- لا تُضاف فيديوهات أو تسجيلات وهمية؛ تعرض طرق الوسائط المتوفرة لكل مادة.

## تنظيم الكود

- Bloc/Cubit لإدارة الحالة؛ وحدات منفصلة للمواعيد والعبادات والمكتبة والاختصارات.
- مستودعات بواجهات واضحة وحقن اعتماديات؛ طبقة UI لا تعرف SQL أو تفاصيل السيرفر.
- DocumentStore مشترك فوق Drift، وترقية قاعدة البيانات من ٥ إلى ٦ تحافظ على الجداول الحالية.
- معاملات ذرية للقضاء وإتمام الورد، ومعرّفات ثابتة وإصدارات لمنع الكتابة المتعارضة.
- أخطاء الحفظ والإذن وتشغيل الوسائط تظهر مع مسار إعادة محاولة؛ العمليات المتأخرة لا تحدّث شاشة أُغلقت.
- ملف البنية: [ARCHITECTURE.md](ARCHITECTURE.md).

## التحقق المتكرر

شغّل من PowerShell:

```powershell
./scripts/verify_mobile.ps1 -FlutterPath D:/Prog/flutter/bin/flutter.bat
# إضافة -BuildAndroid للتحقق من بناء APK كذلك
```

الفحص يغطي التحليل الثابت والاختبارات. صور الواجهات الجديدة في
`report/ui/features/`، والتقويم في `report/ui/planner/`. اختبارات العرض تشمل
العربية والإنجليزية والأوردية والشاشات الصغيرة والنص المكبّر. لا يمكن لأي
مجموعة اختبارات ضمان غياب الأعطال في كل جهاز؛ نتائج التشغيل الفعلي تُسجل أدناه.

## ميزات محذوفة

- حُذف تشغيل الأذان والإقامة بالكامل (الشاشتان، خدمة التنبيه الصوتي، مفاتيح الإعدادات، ملفات الصوت). تبقى مواقيت الصلاة وتتبع القضاء، وتبقى مكتبة `adhan_dart` للحساب فقط.
- حُذفت جميع إشعارات/منبهات أوقات الصلاة وجميع تذكيرات الأذكار (شاشة التذكيرات، خدمة منبه الذكر، قناة `reminders`، جدول `reminders` بترحيل المخطط 8، شريط التذكيرات في الرئيسية، مفتاح تذكيرات الأذكار في الإعدادات). تبقى المنبهات الشخصية وتذكيرات الموعد والورد، ونصيحة اليوم (10:00) وملخص التسبيح (21:00).
- حُذف المصحف داخل التطبيق (شاشة القرآن، التنزيل، التجويد). تبقى خطة الورد وفتح تطبيق قراءة خارجي.
- أصبح الشريط السفلي أربع تبويبات: الرئيسية، الصلاة، الأذكار، التسبيح.
