# Audio Assets for Ramadan Assistant

Add the following audio files to this folder:

## Required Files:

### Tasbih Sounds
- `tasbih_click.mp3` - Click sound for tasbih counter
- `tasbih_complete.mp3` - Sound when reaching tasbih goal

### Dhikr Audio (Optional)
- `salawat.mp3` - الصلاة على النبي
- `subhanallah.mp3` - سبحان الله
- `alhamdulillah.mp3` - الحمد لله
- `allahuakbar.mp3` - الله أكبر
- `lailaha.mp3` - لا إله إلا الله
- `astaghfirullah.mp3` - أستغفر الله
- `hasbiyallah.mp3` - حسبي الله ونعم الوكيل
- `morning_adhkar.mp3` - أذكار الصباح
- `evening_adhkar.mp3` - أذكار المساء
- `ayat_kursi.mp3` - آية الكرسي

## Free Resources:
- Adhan: https://www.islamcan.com/audio/adhan/
- Quran Audio: https://quranicaudio.com/
- Islamic Sounds: https://www.freesound.org/ (search for "adhan" or "islamic")

## Notes:
- All files should be in MP3 format
- Recommended sample rate: 44.1kHz
- Keep file sizes under 2MB for faster loading
